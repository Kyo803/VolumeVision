# Starter GIFs

Three ready-made animated wallpapers for V². All are **436 × 96** — the ideal size for the pill.

| File | Look |
|---|---|
| `v2-wallpaper.gif` | Blue / indigo liquid drips |
| `preset3.gif` | Yellow lava-lamp blobs |
| `preset33.gif` | Pink / red flowing waves |

## How to use them

1. Download the GIF(s) you want (click the file above → **Download raw file**).
2. Put them in this folder:
   ```
   %AppData%\VolumeOSD\gifs\
   ```
   (paste that path into Explorer's address bar)
3. Open V² → **Settings → GIF Library** → click the pill you want, or
   press **`Alt+Shift+W`** to cycle through them on the fly.

> Tick **Animations Only** in Settings so the GIF shows at full vibrancy (it drops the solid glass tint over the art).

## Making your own

Use the built-in **Wallpaper Studio** (Settings → Wallpaper Studio): open any image, crop, draw, colour-grade, animate frame-by-frame or with Ken Burns, then **Export GIF** — it lands straight on the pill. Use **Save GIF as…** to write it to a file you can share.
